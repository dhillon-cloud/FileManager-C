# File Manager System
A File Management System developed using C programming.

## Features
- Create files
- Delete files
- Rename files
- Read files
- Write and modify files
- Display directory contents

## Technologies Used
- C Programming
- Standard C Libraries
- File Handling

## How to Run
Compile:
gcc main.c -o filemanager

Execute:
./filemanager
